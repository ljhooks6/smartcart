# MealCaddie colors

The palette uses deep pine (#174b3c), peach (#ffb074), warm cream (#fff7e9), sage (#b6d78a), and dark green ink (#202c28). The shared orange scale uses burnt orange (#b94d28) for actions with white text; lighter peach shades are used for backgrounds and badges.

The home action combines a deep green card with a peach button. The active bottom tab uses a solid green icon pill. Account uses a pale sage button, dinner cards have peach accents, saved recipes use sage, and sweet treats use berry. Recipe and Account dialog headers use cream. Warning and error colors retain their existing meanings.

Measured contrast ratios for the primary combinations: white on pine 9.96:1, white on orange 5.05:1, ink on peach 8.07:1, pine on cream 9.36:1. These are checks of the specified solid color pairs, not a claim of a complete accessibility audit.

Validation: Node 22 production build, sign-in and all six phone tabs at 390 pixels, narrow phone at 320 pixels, and desktop at 1280 pixels. The palette changes presentation only.
